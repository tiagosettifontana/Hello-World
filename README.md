Hello World in Python 🌍

## Description
The classic first program for any aspiring developer. This is a simple Python script that prints a greeting message to the console, confirming that the Python environment is set up and running correctly.

## Context
This was my very first hands-on assignment in the "Programming for Everybody (Getting Started with Python)" course from the University of Michigan on Coursera. It marks the official beginning of my programming journey!

## Skills Demonstrated
* **Basic Syntax:** Understanding how a basic Python script is structured and executed.
* **Output:** Using the built-in `print()` function to display text strings on the screen.
